# Soluna — Roadmap

## Roadmap Name

# Autonomous Landscape Industry Roadmap (ALIR)

The long-term vision is to automate the full outdoor design and build journey.

The near-term goal is to build the first practical customer-facing layer.

---

## Product Roadmap: V1 to V10

## V1 — AI Yard Preview

### Goal
Capture homeowner interest with a fast, mobile-first photo upload experience.

### Features
- Upload yard photo
- Guided photo instructions
- Choose landscape style
- Choose budget level
- Pick desired features
- Generate AI concept image
- Capture lead info
- CTA to get estimate from local pro

### Platform
Mobile-first web app.

---

## V2 — Top-View Property Layout

### Goal
Use top-down property images for better layout planning.

### Features
- Upload satellite/top-view screenshot
- Identify rough zones
- Mark front/back/side yards
- Sketch simple functional layout
- Generate overhead concept options

---

## V3 — Enhanced Design Package

### Goal
Create more useful concept packages.

### Features
- 3 design options
- Basic / Mid / Luxury versions
- Design explanation
- Rough scope
- Optional paid upgrade
- Downloadable concept package

---

## V4 — Contractor Lead Dashboard

### Goal
Help contractors receive and manage qualified leads.

### Features
- Contractor accounts
- Lead inbox
- Lead package view
- Accept/reject leads
- Contact customer
- Status tracking

---

## V5 — Editable Design Layers

### Goal
Move from static AI images to interactive planning.

### Layers
- Zones
- Surfaces
- Plants
- Lighting
- Irrigation
- Features
- Budget

### Features
- Toggle layers
- Edit preferences
- Regenerate concepts
- Save versions

---

## V6 — Material List Generator

### Goal
Convert designs into rough material lists.

### Features
- Generate bill of materials
- Estimate quantities
- Suggest local material types
- Break materials by phase
- Prepare contractor-friendly material summary

---

## V7 — Estimate Builder

### Goal
Generate rough project pricing.

### Features
- Labor categories
- Material categories
- Budget ranges
- Upgrade/downgrade suggestions
- Contractor proposal helper

---

## V8 — LiDAR / Advanced Capture

### Goal
Improve spatial accuracy for serious projects.

### Platform
Native iOS app or iOS capture companion.

### Features
- ARKit LiDAR scan
- Guided scanning flow
- Basic 3D model
- Mark yard corners
- Mark trees/structures
- Export scan data into project file

---

## V9 — Permit / Compliance Assistant

### Goal
Help guide users and contractors through legal requirements.

### Features
- Local rule checklist
- Setback awareness
- Tree rule awareness
- Drainage considerations
- Fire hazard considerations
- Permit document guidance

### Important
This should be guidance, not legal certification.

---

## V10 — Ordering + Project Automation

### Goal
Connect design to execution logistics.

### Features
- Supplier inventory lookup
- Material ordering
- Delivery scheduling
- Job phase sequencing
- Contractor workflow
- Future robotics/machine integrations

# Full Industry Automation Roadmap

## Phase 1 — Digital Capture

### Goal
Turn any property into usable digital input.

### Inputs
- Photo
- Top-view image
- Video
- LiDAR
- Drone/pro scan later

### Output
- Visual concepts
- Basic layout
- Project file

---

## Phase 2 — AI Design Engine

### Goal
AI helps the user design their yard.

### Capabilities
- Style suggestions
- Climate-aware plant suggestions
- Budget tiers
- Feature recommendations
- Visual concepts

---

## Phase 3 — High-Accuracy Scan

### Goal
Create precise base models for serious planning.

### Tools
- iPhone LiDAR
- External LiDAR
- RTK devices
- Drones with LiDAR/RTK
- Control points

### Output
- Accurate measurements
- 3D model
- Future plan-ready base data

---

## Phase 4 — Permit / Legal Automation

### Goal
Automate as much of the compliance process as possible.

### Capabilities
- Zoning checks
- Setback checks
- Drainage checks
- Fire code checks
- Tree regulation checks
- Permit package generation

---

## Phase 5 — Material Intelligence

### Goal
Turn designs into orderable materials.

### Capabilities
- Bill of materials
- Local inventory search
- Supplier pricing
- Substitutions
- Delivery timing
- Phased ordering

---

## Phase 6 — Secure Delivery + Staging

### Goal
Make jobsite delivery organized and safe.

### Concepts
- Smart storage containers
- Cameras
- GPS trackers
- Delivery instructions
- Phase-based staging
- Material verification

---

## Phase 7 — Semi-Automated Execution

### Goal
Use machines to assist humans.

### Examples
- Layout marking
- Trenching
- Grading
- Material movement
- Drone monitoring

---

## Phase 8 — Robotic Specialization

### Goal
Robots handle specific tasks.

### Examples
- Irrigation install
- Paver placement
- Planting
- Soil prep
- Repetitive hauling

---

## Phase 9 — Integrated Jobsite System

### Goal
AI coordinates all jobsite activity.

### Capabilities
- Schedule control
- Progress tracking
- Weather adjustments
- Delivery coordination
- Issue detection
- Contractor/robot communication

---

## Phase 10 — Full Autonomy

### Goal
One-click outdoor transformation.

### Future Flow
1. Scan property
2. AI designs
3. User approves
4. Permits submitted
5. Materials ordered
6. Materials delivered
7. Robots install
8. System maintains landscape

---

# Near-Term Focus

Do not chase full automation immediately.

Start with:

1. Photo upload
2. AI concept generation
3. Lead capture
4. Contractor referral
5. Paid design upgrade

The first winning product is the front-end of the future.
